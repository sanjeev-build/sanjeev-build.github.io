EV Vehicle API

Project Overview

This is a scalable EV Vehicle API that facilitates vehicle booking for service delivery. It manages the complete booking flow including vehicle selection, booking, and tracking. The system supports multi-role operations with dedicated Vendor and Admin panels. Built with modular architecture, it enables real-time booking tracking and efficient vehicle management.
